## Content: Reasons for choosing FireBase

My partner(Annabella) and I wanted to create a wishing Simulator where you can pull for different characters. While pulling we wanted to create an animation and for it to save your progress as you obtain more characters. Annabella chose to do Animate.JS to work on the front end of the website while I decided to study [FireBase](https://firebase.google.com/) to make the back end of the website that saves the characters you collected. Another reason why I chose do to FireBase is because I like to challenge myself and FireBase was one of the more challenging tools you can study. 

### How I "Tinkered" with FireBase

So far, I mostly studied the possibilities with Firebase and set it up. Since Firebase is a difficult tool, you can't really play around with it on the same Repository as the Freedom Project. So I started with creating a repository made just for tinkering. You can find this repository [here](https://github.com/evangelinae1225/firebase-tinker1). What I did so for in this Repository is set-up Webpack. The reason I needed to install it was because Webpack helps your browser read tons of separate files more efficiently, which is a great necessity when you have FireBase since it is separated into a lot of files. As well, I added the tool itself to my project. I installed FireBase 9 instead of the most latest one because the tutorial I was using was from a couple years ago. So I will be using slightly different syntax compared to modern FireBase.
